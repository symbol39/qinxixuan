> 你生於凡人世界與不可見之境的交會處，對某些人而言是個謎，對更多人而言則是恐懼的對象。你的故事，訴說著兩個世界碰撞時會發生什麼。

<!--more-->

## 名字

Solena、Veles、Bryn、Sabine、Razvan、Rowena、Galen、Nyx、Vex、Iwan

## 起始裝備

- 3d6 金幣
- 口糧（3次使用）
- 火把（3次使用）
- 法術書（灌木叢：一片寬達50呎的濃密樹叢與灌木突然拔地而生。*每次使用後都會被藤蔓纏繞，須再次破壞方能重複施展。*）
- 鐵製匕首（d6）
- 藥草袋（恢復1點力量，3次使用）
- 迷彩偽裝服

## 你從幽冥宮廷帶回了什麼？擲1d6：

| 點數 | 結果 |
|---|---|
| **1** | 一把**黑玫瑰提琴**（*笨重*）。其樂音會使附近凡人陷入強烈的悲傷與無法動彈的狀態（其他生物則只會單純著迷）。你不知道該如何演奏它。 |
| **2** | **紙腿**。你變得極為輕盈，即使從數層樓高墜落也不會受傷。請盡量避免撕裂它們或讓它們沾濕。 |
| **3** | 一個棲居在你體內的**活體夢魘**，只在你身陷危險時才會顯現。牠擁有與你相同的**屬性值**與**HP**，並以利爪攻擊（d8+d8）。牠會在遭受**重擊傷害**時消失（你將承受1d4點意志傷害），並於下一次滿月時再度現身。 |
| **4** | 一隻**渡鴉使魔**〔8點生命、3點力量、11點敏捷、13點意志，喙擊(d6)〕。牠能以具智能的方式說話，並全心全意效忠於你。 |
| **5** | 一根**荊棘刺**。它能刺穿任何有機材質（相當疼痛），但拔除後不會留下任何刺入的痕跡。 |
| **6** | 一位妖精生物的**真名**。可用來召喚其擁有者，令其提供一次重大協助，但僅限一次。若遇到合適的買家，這也可能賣得一筆可觀的價錢。 |

## 你隨身攜帶著什麼藥劑？你又是採集了哪些稀有材料來製作它？擲1d6：

| 點數 | 名稱 | 效果 |
|---|---|---|
| **1** | **重生之灰** | 樹皮精靈的殘餘物。灑下後可重新點燃已熄滅的火焰，或使剛死去不久的生物復活。3次使用。 |
| **2** | **幻影羽毛** | 火鳥的羽毛。可使任何生物令人信服地偽裝成另一個人（或另一種東西）。1次使用。 |
| **3** | **山楂籽** | 一顆來自彼岸、於春分時採集的橡實。種下後會長出一座奢華的庇護所，並於次日月升時崩塌消失。1次使用。 |
| **4** | **石樹樹脂** | 以鮮血換取而得的樹脂。塗抹於任何表面後會硬化（+1護甲）。3次使用。 |
| **5** | **夜塵粉** | 以儀式焚燒六隻貓頭鷹製成。撒向空中後可使白晝短暫轉為黑夜。2次使用。 |
| **6** | **咒印石** | 採集自一條源自*彼岸*的河流。從鐵盒中取出後，可吸收一個正在生效的魔法效果。若此石被摧毀，該魔法效果將被釋放。1次使用。 |
